# Sprint 1 · Ingeniería inversa

Aquí va tu recreación de 3 pantallas del sitio de referencia (historia H1.2), en
**HTML, CSS y JavaScript puro**, sin TypeScript ni frameworks.

1. Estudia el sitio con DevTools y documenta lo que encuentres en `docs/ingenieria-inversa.md`.
2. Crea una página por pantalla: `index.html`, `listado.html`, `detalle.html`.
3. Usa tu propia marca: nombre, logo, colores e imágenes tuyos.
4. Verifica que se vea bien a 375 px (teléfono) y a 1280 px (computador).
5. Para verla en vivo, abre esta carpeta con la extensión Live Server de VS Code.

Desde el Sprint 2 el producto se construye en `src/` con TypeScript.
